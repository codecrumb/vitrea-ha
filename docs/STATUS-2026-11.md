# Status of the simple-protocol branch (2026-11-05)

This branch moves control and live state to the V-Box's no-login "simple" port **11502**, and keeps the mobile
login for names only. Version `0.5.0-beta.5` is committed here but **not released or tagged**.

## Why it is parked

After the box owner's system upgrade (Control4 was upgraded the same day) port 11502 stopped answering
anything: not the keepalive `P:VITREA`, not `H:N041:G`, not the `VTH>` lookups, even after a 240 s wait and with
the integration off. The mobile port 11503 and the admin port 11501 still respond, and the old Vitrea ControlPro
app still works.

Two untested explanations: Control4's new integration holds 11502 (the box may serve one client there at a time),
or the upgrade changed or disabled the simple protocol. Checking which means asking the installer which port the
Control4 driver uses, or taking Control4 offline and sending `P:VITREA` to 11502.

Details, the new "Vitrea" app (`com.vitrea.controlpro`) and its UDP discovery are in the main repo:
`docs/new-app-and-box-upgrade-2026-11.md` on branch `worktree-new-app-notes` of codecrumb/vitrea.

## What is in the branch and worth keeping

- Simple-protocol client and hub (`_simple_client.py`, `hub.py`); works on firmware 7.91 as of 2026-11-01.
- Names from the admin list (11501, vendor default `admin`/`admin`), falling back to the mobile list, then generic names.
- Options: Hide unnamed keys (on by default), Hidden names (wildcards), Hidden nodes.
- Setup asks for the optional admin login first; the suggested mobile user is `vitrea1`.
- 29 offline tests: `python3 -m pytest -q tests`.

## Ideas not built

- Two modes in one integration (app mode on 11503, API mode on 11502), with setup recommending API mode only if the
  default admin login works.
- Login-free discovery of the box by UDP 11505 (`VITREA-APP`), which still works after the upgrade.
- Opt-in calibration that toggles lights to pair mobile names with simple keys (warns the user; untried).

## If someone picks this up

Check first whether 11502 answers `P:VITREA` on their box. If it does not, nothing on this branch will work for them.
